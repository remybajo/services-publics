Méthode et sources

D'où viennent les chiffres, comment ils sont calculés et comment les refaire.

Comment les chiffres sont produits

Chaque rapport repose sur des données publiques téléchargées telles quelles chez leur producteur. Un script nettoie ces fichiers sans correction à la main : les valeurs manquantes ou suspectes sont signalées, pas supprimées. Un second script calcule chaque chiffre à partir des fichiers nettoyés et l'enregistre avec sa définition. Un troisième produit la page à partir de ces calculs : aucun chiffre n'est saisi à la main dans les textes.

Les limites de chaque donnée figurent à côté du chiffre concerné et dans la section « Fiabilité » de chaque rapport. Les encadrés « Notre lecture » signalent les interprétations.

Reproduire les calculs

Le code est public. Avec Python 3 et sans autre dépendance, après avoir placé les fichiers sources dans donnees_brutes/ :

python3 nettoyer_sante.py && python3 calculer_chiffres_sante.py && python3 generer_rapport_sante.py

Même enchaînement pour transports, poste, logement et education, puis calculer_chiffres_comparaisons.py, calculer_chiffres_territoires.py, generer_rapport_territoires.py et assembler_site.py.
